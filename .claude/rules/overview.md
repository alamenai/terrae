# Project Overview

## Project Name
**Terrae** (pronounced "TER-ray")

## Description
Beautiful Mapbox GL components, made simple. A collection of free and open-source map components built with React, TypeScript, Tailwind CSS, and Mapbox GL JS. Perfect companion for shadcn/ui.

## Tech Stack
- **Framework**: Next.js 16.1.1
- **Language**: TypeScript 5
- **UI Library**: React 19.2.3
- **Styling**: Tailwind CSS 4
- **Map Library**: Mapbox GL JS 3.8.0
- **Component System**: shadcn/ui patterns
- **Theme Support**: next-themes

## Purpose
Provide declarative, composable map components that:
- Work seamlessly with modern React and shadcn/ui
- Reduce complexity of implementing interactive maps
- Follow declarative patterns instead of imperative code
- Offer beautiful, ready-to-use map components

## Key Features
- Individual component installation (like shadcn/ui)
- Dark mode support
- Composable and declarative API
- TypeScript-first development
- Tailwind CSS styling
- Rich component library (markers, popups, clustering, animations, etc.)

## Component Architecture
Components are installed individually via CLI and placed in the project's registry. Users can install only what they need, keeping their bundle size minimal.

### Available Components
- Core: Map, MapMarker, MapPopup, MapControls
- Features: MapMiniMap, MapLine, MapLineAnimated, MapCircleCluster
- Effects: MapAnimatedPulse, MapRain, MapRasterVideo, MapImage
- Utilities: MapCompare

## Development Philosophy
- Keep components minimal and focused
- Follow shadcn/ui patterns for consistency
- Embrace TypeScript for type safety
- Use declarative React patterns
- Support theme customization
